ABOUT THE GAME

01 — THE GAME

たった一本の火が、
勝敗を分ける。

MATCHMANは、火のついた矢とダイナマイトを使って戦うオンライン対戦ゲームです。仲間との連携で挑む3v3、一人で腕を試す1v1。自分の戦い方を選べます。

キャラクターを選び、地形と光を読み、狙いすまして放つ。シンプルな操作の先に、毎回違う駆け引きが待っています。
